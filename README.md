# Hi, we're Velocity Labs!

We're a senior software team based in Phoenix, AZ, building custom software
and web apps since 2009. We also rescue apps that are stuck, clean up vibe
coded ones, add AI to existing apps, and keep them all running. You can find
us on the web at [velocitylabs.io](https://velocitylabs.io) or on twitter
[@velocitylabs](https://twitter.com/velocitylabs).

This repository is the code behind velocitylabs.io: a Jekyll site served by a
small Sinatra app. [DEV_README.md](DEV_README.md) covers running it locally,
how it's put together, and how it deploys.

--- layout: base --- {%- comment -%} A service page. Front matter: service (its id in _data/services.yml, which names the page, is sent with the contact form and records its Ads conversion), heading, lede, cta, faq (a list of { q, a }), and optional eyebrow (default: the service's name), hero_report (true or a set in images/code-audit/: a sample report's pages in the hero instead of the rings), versions (a file in _data/versions/ for blocks/version-panel.html), faq_title, contact_heading, contact_lede, contact_question.
